# 2Lip Physics 🌷

เว็บไซต์เรียนฟิสิกส์ ม.6 พร้อม simulation ทั้ง 8 บท
เวอร์ชันธีมชมพู–ม่วงและทิวลิป วันที่ 28 กันยายน 2026

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วยเว็บเบราว์เซอร์ เช่น Chrome, Edge หรือ Firefox
ไม่ต้องติดตั้งแพ็กเกจและไม่ต้องใช้ API key

หากต้องการเปิดผ่านเซิร์ฟเวอร์ท้องถิ่น และเครื่องมี Python:
```sh
python -m http.server 8000
```
แล้วเปิด http://localhost:8000

## ไฟล์
- index.html — โครงสร้างหน้าเว็บและชื่อเว็บ
- style.css — ธีม สี และการจัดหน้าสำหรับมือถือ/คอมพิวเตอร์
- lessons.js — เนื้อหา สูตร ตัวแปร ตัวอย่าง และค่าปรับของทั้ง 8 บท
- app.js — การนำทาง สมการ ภาพจำลอง Canvas และปุ่มควบคุม

## การแก้ไข
- เปลี่ยนข้อความหรือชื่อใน index.html และชื่อแท็บใน app.js
- ปรับธีมส่วนท้าย style.css ใต้คอมเมนต์ 2Lip Physics
- แก้เนื้อหาใน lessons.js และการวาด simulation ใน app.js
- บันทึกไฟล์เป็น UTF-8 เพื่อรักษาภาษาไทย

## เทคโนโลยี
HTML, CSS, JavaScript และ Canvas API แบบไม่มีเฟรมเวิร์ก
สามารถนำไฟล์ทั้ง 4 ไปวางบน static hosting ได้โดยไม่ต้อง build
ไม่มี backend, ฐานข้อมูล, รหัสผ่าน หรือข้อมูลบัญชีในชุด source นี้
สิทธิ์ส่วนตัวของเว็บเดิมเป็นการตั้งค่าของโฮสต์ ไม่ได้ติดไปกับชุด source นี้
